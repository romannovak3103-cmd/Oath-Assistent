# Голосовой ассистент для задач и встреч

Говорите или пишете в свободной форме: ассистент создаёт задачи, напоминания и встречи, показывает планы за период и ищет старые записи. Работает с Claude API или с бесплатной локальной моделью (Ollama).

## Запуск

Нужен Python 3.10+ и Chrome/Edge/Safari (микрофон работает на `localhost` и по HTTPS).

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
uvicorn app.main:app --reload
```

Откройте http://localhost:8000.

### Модель (выберите один вариант в `.env`)

**Бесплатно, локально (Ollama).** Установите Ollama с ollama.com, выполните `ollama pull llama3.1:8b` и оставьте в `.env` значения по умолчанию (`LLM_PROVIDER=ollama`). Если ассистент «забывает» начало длинного диалога или путает инструменты, запускайте Ollama с большим контекстом: `OLLAMA_CONTEXT_LENGTH=8192`. Подойдёт и любой другой сервер с OpenAI-совместимым API: поменяйте `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `MODEL`.

**Claude API.** В `.env` укажите `LLM_PROVIDER=anthropic`, `MODEL=claude-sonnet-5-5` и `ANTHROPIC_API_KEY`.

Маленькие локальные модели хуже понимают даты и иногда ошибаются в вызове инструментов. Для этого в промпт передаётся календарь на 15 дней вперёд, а ошибки инструментов возвращаются модели текстом, чтобы она исправилась сама.

### Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не требуют ни ключа, ни Ollama: LLM подменяется заглушкой.

### Docker

```bash
docker build -t va .
docker run -p 8000:8000 --env-file .env va
```

Если модель крутится в Ollama на хосте, укажите `OPENAI_BASE_URL=http://host.docker.internal:11434/v1`.

### Деплой (Render / Railway)

Web Service из репозитория, команда `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, переменные из `.env.example`. Локальная Ollama в облаке недоступна, поэтому для публичной ссылки нужен `LLM_PROVIDER=anthropic` (или другой облачный OpenAI-совместимый сервис). Для сохранности SQLite между перезапусками подключите persistent disk и задайте `DB_PATH`.

## Архитектура

```
Браузер
  static/voice.js     голос: микрофон → Web Speech API (STT) → текст ──► POST /api/chat
  static/index.html   интерфейс                       ответ ◄── Web Speech API (TTS)

Сервер
  app/main.py         api       HTTP, определение пользователя, коды ошибок
  app/assistant.py    llm       системный промпт, история сессий, цикл «модель → инструменты»
  app/tools.py        llm       схемы инструментов и их вызов
  app/llm.py          llm       провайдеры: Claude / OpenAI-совместимые (Ollama)
  app/services.py     services  правила, валидация дат, конфликты встреч
  app/storage.py      storage   SQLite, период, поиск
```

| Слой | Файлы | Ответственность |
|---|---|---|
| voice | `static/voice.js` | STT и TTS в браузере, без серверных ключей. Заменяется на Whisper реализацией тех же двух функций |
| llm | `assistant.py`, `tools.py`, `llm.py` | понимание запроса, tool use, диалоговый контекст; не знает про SQL |
| services | `services.py` | вся бизнес-логика; не знает ни про LLM, ни про HTTP |
| storage | `storage.py` | только SQL |
| api | `main.py` | тонкая обёртка над ассистентом и сервисами |

Запись: `id, user_id, type (task|meeting|reminder), title, due_at, created_at, status (open|done)`.

## Принятые решения

- **LLM с tool use вместо правил и регулярок.** Модель получает текущую дату, часовой пояс и календарь на ближайшие дни и сама разрешает «завтра», «в пятницу», «через два часа»; разные формулировки сводятся к одному инструменту.
- **Нейтральный формат истории и два провайдера.** Диалог хранится не в формате конкретного SDK, поэтому Claude и локальная модель взаимозаменяемы одной переменной в `.env`.
- **Ошибки инструментов возвращаются модели.** Неверная дата, неизвестный id, встреча без времени дают `{"error": ...}`, и модель переспрашивает или исправляет вызов; сервер не падает.
- **Уточнения.** Для встречи без времени сервис отвечает ошибкой, и ассистент задаёт вопрос. Правило закреплено и в промпте, и в коде.
- **Поиск.** Модель разворачивает запрос в ключевые слова и синонимы, поиск идёт SQL `LIKE` по основам слов с ранжированием по числу совпадений. Родной `LIKE` в SQLite не различает регистр кириллицы, поэтому подключена функция `py_lower`. Эмбеддинги не используются.
- **Контекст диалога.** История сессии в памяти процесса (до 200 сессий, 60 сообщений на сессию), поэтому работает «перенеси её на завтра». При ошибке модели оборванный обмен удаляется из истории.
- **Бонусы:** изменение, удаление, «выполнено», конфликты встреч (пересечение ближе часа), несколько пользователей (заголовок `X-User-Id`, в браузере генерируется и хранится локально).
- **Время.** Все даты, включая `created_at`, считаются в `TIMEZONE`, а не в часовом поясе сервера.
